# Belajar Tailwind CSS - Proyek Pembelajaran

Repository ini berisi kode pembelajaran Tailwind CSS

## 🎯 Tujuan
- Memahami konsep utility-first CSS
- Menguasai dasar-dasar Tailwind CSS
- Membuat komponen responsif dengan Tailwind

## 📁 Struktur Proyek
belajar_tailwind/
├── img
├── index.html # File utama pembelajaran
└── README.md # Dokumentasi proyek


## 🚀 Cara Menjalankan
1. Clone repository ini
2. Buka file `index.html` di browser
3. Mulai eksplorasi dan modifikasi kode

## 📚 Materi yang Dipelajari
- [x] Dasar Utility Classes
- [x] Layout dengan Flexbox & Grid
- [x] Responsive Design
- [x] Komponen dengan Tailwind

## 💡 Tips Belajar
- Gunakan VS Code dengan extension Tailwind CSS IntelliSense
- Coba ubah nilai-nilai class Tailwind untuk melihat efeknya
- Praktekkan dengan membuat komponen sederhana
