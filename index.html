📚 Apa itu Tailwind CSS?

Tailwind CSS adalah framework CSS utility-first yang memungkinkan kita membangun desain langsung di HTML dengan kelas-kelas utilitas.

💡 Konsep Utama:

  • Tidak ada komponen siap pakai seperti Bootstrap
  • Kita membangun desain dengan menggabungkan kelas-kelas kecil
  • Memudahkan customisasi tanpa meninggalkan HTML

📱 Responsive Design

Tailwind menggunakan mobile-first breakpoints. Kelas tanpa prefix berlaku untuk semua ukuran, sementara prefiks seperti md:, lg: hanya berlaku mulai breakpoint tertentu.

📋 Breakpoints Default Tailwind:

  • sm: ≥640px
  • md: ≥768px
  • lg: ≥1024px
  • xl: ≥1280px
  • 2xl: ≥1536px

💡 Tips Belajar Tailwind CSS

Hal yang Perlu Diingat

  • ✓ Tailwind adalah utility-first, bukan komponen siap pakai
  • ✓ Gunakan VS Code dengan extension Tailwind CSS IntelliSense untuk autocomplete
  • ✓ Pelajari pola naming: property-direction-size atau property-size
  • ✓ Jangan takut menggabungkan banyak kelas, itu normal di Tailwind
